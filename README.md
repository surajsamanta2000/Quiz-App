🧠 Quiz App
----------------
A simple, responsive quiz application built using HTML, CSS, and JavaScript. This app allows users to test their knowledge with multiple-choice questions and get instant feedback on their answers.

🚀 Features
----------------
📝 Multiple-choice quiz questions
✅ Instant answer validation
⏱️ Timer for each question (if applicable)
📊 Score tracking
🔁 Restart quiz functionality
🎨 Simple and responsive UI

🛠️ Technologies Used
----------------------
Frontend: HTML5, CSS3, JavaScript
Version Control: Git & GitHub
